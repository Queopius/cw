# Plugin candidate support

CW Plugin 0.1.0 technical support covers the local candidate, Secure MCP Tunnel
development evaluation, and staging MCP/OAuth testing. Staging is not a
production service. Historical acceptance documents are evidence records, not
a hosted-service commitment.

CW — Codex Workflow is published technically by Fantomid LLC under the Queopius
technology brand. Queopius is a technology brand operated by Fantomid LLC,
a New Mexico limited liability company.

- Documentation: <https://docs.cwcli.dev>
- Plugin documentation: <https://docs.cwcli.dev/en/stable/plugin-app-candidate/>
- Public issues: <https://github.com/Queopius/cw/issues>
- Security reports: follow the private process in
  [SECURITY.md](https://github.com/Queopius/cw/blob/dev/SECURITY.md).
- Source and license: <https://github.com/Queopius/cw>

Include the CW version, plugin version, operating system, Codex/ChatGPT surface,
sanitized error code, and operation ID when reporting a problem. Do not include
credentials, `.env`, private source, raw reviewer prompts, or unrestricted
logs.

There is no service-level agreement, production hosted runtime, production
ChatGPT web connection, or public Plugin Directory availability in this
candidate. Final commercial support commitments require human approval before
submission.
